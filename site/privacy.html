Architecture & Guarantees

Privacy & Storage Architecture

Pathfolio is built on a simple premise: your job search, compensation targets, and interview notes should never live on someone else's server.

1. Zero Remote Storage & Zero Telemetry

Pathfolio does not operate a user database, auth server, or analytics backend. When you use the web application or install the Android APK, all data is written directly to your client sandbox:

  • Web: Records are saved locally in browser storage via shared_preferences (backed by browser localStorage), scoped solely to your current browser profile.
  • Android: Records are saved locally in sandboxed application storage via shared_preferences.
  • Network Calls: The only outbound network requests made are when you explicitly click an external link to visit a company's job posting or GitHub repository.

2. Browser Storage Limitations & Best Practices

Because your browser manages the local storage sandbox, certain user actions or browser maintenance tasks can impact your data:

  • Clearing your browser's "Site Data and Cookies" will remove locally stored opportunities and tasks.
  • Incognito or Private Browsing mode will discard records once the private window is closed.
  • Browsers on different devices or across different user profiles cannot automatically synchronize data without a server.

Recommended Backup Practice

Use the built-in Export JSON Backup feature in Settings regularly. Saving this file to your personal computer or private cloud drive ensures your records can be restored instantly anywhere.

3. Data Export, Import & Erase Guarantees

You retain full sovereignty over your information:

  • Export: Produces a plain, human-readable, schema-versioned JSON file containing all opportunities, timeline events, follow-ups, and evidence items.
  • Import: Validates payload size, JSON syntax, required fields, and schema version before modifying any local records. If validation fails, your existing data remains untouched.
  • Erase All Data: A confirmed two-step action that wipes all keys, real records, and demo workspace records from device storage.
