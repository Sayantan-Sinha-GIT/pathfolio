REBUILD ON ANOTHER COMPUTER
Install Flutter 3.47.7, Node.js 22 or 24, and an Android SDK/JDK for Android.
From the project folder:
  npm ci
  cd app
  flutter pub get
  flutter test
  cd ..
  npm run build
  npm run preview
Open http://127.0.0.1:8086/ (working app at /app/).
If Flutter is not on PATH, set FLUTTER_BIN to your flutter executable first.
Windows example: $env:FLUTTER_BIN='C:\path\to\flutter\bin\flutter.bat'

For a signed Android rebuild, first restore the signing files according to
PRIVATE_RECOVERY/README.txt, then run: npm run build:apk
For a Pages update: npx wrangler pages deploy dist --project-name pathfolio
This project deliberately uses Cloudflare Pages Direct Upload.

YOUR DATA
Records stay on the current browser profile or Android installation.
Settings -> Export JSON Backup -> Save Backup File makes a portable backup.
Settings -> Open Backup File validates and previews it before replacement.
Copy/paste JSON remains available as a fallback. There is no cloud sync.
The web app needs a complete first online load before offline use; Android
works offline after installation. Clearing site data removes local records.
Your personal job-search records are not copied into the source archive.
